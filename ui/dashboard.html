🎯 Find Teammates

The matcher finds classmates who fill the gaps in your team, then ranks the strongest top 5 by:

  • ✓ Same cohort city (HK or SH)
  • ✓ Roles your team is missing (Frontend, Backend, Database, Agentic Development)
  • ✓ Skills that fit you (programming, GitHub, debugging, web, AI agents)
  • ✓ Shared languages and programme diversity
  • ✓ Availability (not already in a team)

Off uses the deterministic scorer with the same signals and no API call.

📋 How Matching Works

1

Hard Filter

We remove anyone who cannot join your team: a different cohort city, classmates already in a team, and yourself.

2

Signal Analysis

Each remaining classmate is scored on role gaps, complementary skills, open-role flexibility, shared languages, and programme mix.

3

Team Assembly

The AI model weighs those signals to assemble a balanced top 5. With the switch off, or no API key, a deterministic scorer applies the same rubric.
